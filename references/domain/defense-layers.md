# Defense Layers Model (L0-L5)

## Overview

The defense-in-depth model for base-building games organizes defensive measures into six concentric layers (L0-L5). Each layer serves a specific purpose and contributes to the overall defensive posture. The model prioritizes layered defense over single concentrated layers, as depth provides redundancy and mitigates single points of failure.

## Layer Definitions

### L0: Outer Detection Zone
**Purpose:** Early warning and deterrence
**Components:**
- Detection systems (surveillance cameras, sensor arrays)
- Deterrent signage and visual barriers
- Long-range engagement capabilities (sniper positions)
- Outer lighting for night visibility

**Metrics:** Detection radius, false positive rate, response time enabled

### L1: Perimeter Barrier
**Purpose:** Physical boundary and first line of defense
**Components:**
- Outer walls or fences
- Gate controls and access points
- Basic perimeter traps (sap traps, barricades)
- Anti-climb measures

**Metrics:** Wall height, material strength, breach time, gate coverage

### L2: Funneling Chokepoints
**Purpose:** Channel attackers into kill zones
**Components:**
- Tunneled corridors with funnels
- Chokepoint traps (shotgun traps, flame turrets)
- Visibility restrictions (turns, blind corners)
- Concentrated fire positions

**Metrics:** Funnel efficiency (attackers per width), trap density, convergence ratio

### L3: Layered Kill Zones
**Purpose:** Eliminate attackers in depth
**Components:**
- Multiple rows of traps with spacing
- Cross-fire patterns
- Height-varied targets (high/low traps)
- Anti-raid measures (router traps, device protection)

**Metrics:** Kill zone depth, trap overlap, TTK (Time To Kill)

### L4: Inner Sanctuary
**Purpose:** Protect critical assets and fallback position
**Components:**
- Inner reinforced walls
- Secure storage rooms
- Defensive fallback positions
- Emergency escape routes

**Metrics:** Sanctuary coverage, asset protection rate, escape route availability

### L5: Tool Cupboard (TC) Core
**Purpose:** Prevent building privilege loss
**Components:**
- Tool cupboard placement and coverage
- TC protection and redundancy
- Building privilege radius optimization
- Backup TC positioning

**Metrics:** TC coverage radius, redundancy factor, privilege denial prevention

## Layer Interaction

Layers work synergistically:
1. **Early Detection (L0)** enables response preparation
2. **Perimeter (L1)** buys time for inner layers
3. **Funneling (L2)** concentrates attackers for efficient engagement
4. **Kill Zones (L3)** deliver maximum damage
5. **Sanctuary (L4)** protects critical assets if outer layers breach
6. **TC Core (L5)** prevents total building loss

## Design Principles

1. **Depth Over Breadth:** Multiple layers beat single thick layers
2. **Redundancy:** Critical functions covered by multiple layers
3. **Progressive Escalation:** Outer layers delay, inner layers eliminate
4. **Cost Efficiency:** Higher-cost materials closer to core
5. **Counter-Play Balance:** No layer should be impenetrable

## Common Anti-Patterns

- **Single Thick Wall:** No depth, vulnerable to breach at any point
- **All Traps at Entrance:** Predictable, easily countered
- **No Funnels:** Attackers can choose optimal path
- **TC Exposed:** Single point of failure for entire base
- **No Detection:** Reactive instead of proactive defense
